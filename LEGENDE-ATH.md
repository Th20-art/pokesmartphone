# Légende ATH

[Retour aux mods](README.md)

L'interface de PokeIsland façon carnet d'explorateur (équipe, Pokédex, fiches, évolutions, PC, pâturage, carte de l'île).

Dernière version : **0.65.12**  [**⬇ Télécharger**](https://github.com/Th20-art/pokesmartphone/raw/main/legende-ath-0.65.12.jar)

## Installer ou mettre à jour

1. Clique sur **Télécharger** ci-dessus : le fichier `legende-ath-0.65.12.jar` s'enregistre.
2. Ferme le jeu.
3. Dans ton dossier `mods`, supprime l'ancienne version du mod s'il y en a une, et glisse le nouveau à sa place.
4. Relance le jeu.

Il faut Minecraft 1.21.1 avec Fabric, Fabric API et Cobblemon (déjà présents dans le pack PokeIsland). Quand une nouvelle version sort, le mod te prévient dans le tchat : refais simplement ces étapes.

## Masquer les panneaux PokeIsland

Depuis la version 0.64.1, le mod masque ces panneaux automatiquement quand l'ATH est actif. Si tu as appliqué le correctif manuel précédent, tu peux restaurer ta sauvegarde de config/pokeisland.json pour retrouver tes réglages en mode classique.

## Touches

- **Pavé numérique `*`** : revenir à l'affichage classique
- **:** : carte de l'île (ou `/pokeworld`)
- Les touches se changent dans Options, Commandes.
