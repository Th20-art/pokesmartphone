# Tchat Commerce

[Retour aux mods](README.md)

Le tchat de PokeIsland en sections à déplier : Général, Commerce (les offres de vente), Groupes (avec le PokéSmartphone) et Modération pour le staff. Têtes des joueurs, prix de la GTS sur les offres, mise en relation des acheteurs et des vendeurs, rappels. Le menu « Écrire dans » envoie tes messages aux canaux de PokeIsland.

Dernière version : **1.30.2**  [**⬇ Télécharger**](https://github.com/Th20-art/pokesmartphone/raw/main/tchat-commerce-1.30.2.jar)

## Installer ou mettre à jour

1. Clique sur **Télécharger** ci-dessus : le fichier `tchat-commerce-1.30.2.jar` s'enregistre.
2. Ferme le jeu.
3. Dans ton dossier `mods`, supprime l'ancienne version du mod s'il y en a une, et glisse le nouveau à sa place.
4. Relance le jeu.

Il faut Minecraft 1.21.1 avec Fabric, Fabric API et Cobblemon (déjà présents dans le pack PokeIsland). La bibliothèque du PokéSmartphone (bouton « Mod MotisPack ») te dit quand une nouvelle version sort.

## Touches

- **T** : ouvrir le tchat, comme d'habitude
- **⚙** (tchat ouvert) : les réglages, les listes de mots, le retour au tchat d'origine

# Mises à jour

## 1.30.2 (25/11/2026)

- MotisPack permet d’arrêter en jeu le traitement des messages, les annonces et l’interface de Tchat Commerce.

## 1.30.1 (25/11/2026)

- Les réglages MotisPack permettent de revenir au tchat du serveur et de réactiver Tchat Commerce immédiatement.

## 1.30.0 (25/11/2026)

- L’entrée en file Ranked peut être annoncée dans le tchat, avec un délai de 15 minutes entre les annonces et un réglage pour les désactiver.
- Les joueurs qui ont le mod peuvent rejoindre une file 1v1, 2v2 ou Random depuis le bouton correspondant. Une demande comme « qui ranked ? » affiche aussi un raccourci.
- Les canaux Commerce et Staff suivent le nouveau tchat PokeIsland. Les messages de Vente, Recrutement, Staff et les réponses MP peuvent être envoyés depuis le menu « Écrire dans ».
